# Shift schedule TNC — Prototype documents

แอปปัจจุบันอยู่ `apps/api/` และ `apps/web/` ใช้ข้อมูลสมมติและ PostgreSQL รายละเอียดขอบเขตและผลตรวจอยู่ใน [Alpha Demo implementation](alpha-demo.md)

ต้นแบบ static เดิมย้ายจาก `shift/` ไปเก็บใน [prototypes/legacy-static](../../../prototypes/legacy-static/README.md) เอกสาร UI design เดิมที่เคยอยู่ในไฟล์นี้เก็บครบที่ [ui-design-spec.md](../../../prototypes/legacy-static/docs/ui-design-spec.md) รายงานตรวจเดิมอยู่ข้างต้นแบบใน `reviews/`

เอกสารเก่าเป็นหลักฐานของต้นแบบ ณ เวลานั้น อาจมีชื่อ ShiftFlow และ path `shift/` ตามเดิม ขอบเขตแอปปัจจุบันให้ดู Alpha Demo implementation และ requirements ที่ยังรอยืนยัน ไม่ถือว่า feature ของต้นแบบเก่าทุกตัวเชื่อม Backend แล้ว
