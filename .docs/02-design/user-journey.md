# User Journey

## 1. Shift Supervisor
- View personal and team shift schedules
- View the dashboard and key summary information
- Track the status of submitted requests
- Submit shift swap requests within the same team or across teams
- Submit OT requests
- Submit leave requests
- Submit retrospective leave and OT documentation
- Select public holiday entitlement
- Export schedule data (CSV/Excel)
- Create and edit shift schedules
- Adjust employee shift schedules
- Manage employees within teams
- Review and approve/reject shift swap requests
- Review and approve/reject OT requests
- Review and approve/reject leave requests
- Publish the monthly shift schedule
- Participate in multi-level approval processes
- View audit logs and change history

## 2. HR & Management
- View shift schedules
- Export schedule data (CSV/Excel)
- Export leave records
- Export OT records
