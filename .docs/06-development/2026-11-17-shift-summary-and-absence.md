# สรุปตารางกะและการบันทึกขาดงาน

วันที่ 17 พฤศจิกายน 2569

สรุปรายเดือนใช้ช่วงเวลาของกะที่มีผลในตาราง เพื่อแสดงชั่วโมงและจำนวนกะให้พนักงานตรวจสอบได้ รวมชั่วโมงกะคร่อมวันตามวันเริ่มกะ แยกกะปกติ OT ปกติ OT นักขัตฤกษ์ ลา และขาดงานออกจากกัน ยอดรวมเวลาทำงานไม่นับกะที่บันทึกขาดงานและไม่รวมเวลารับ–ส่งกะหรือตัวคูณค่าตอบแทน

## การเก็บและใช้ข้อมูลขาดงาน

- **วัตถุประสงค์** บันทึกผลการตรวจสอบของ Manager รายกะ เพื่อให้ตารางและสรุปแสดงการขาดงานเต็มกะได้ตรงกัน และให้คืนกะเดิมได้เมื่อบันทึกผิด
- **ข้อมูลขั้นต่ำ** รหัสรายการและเวอร์ชันของกะ รหัสกะและช่วงเวลาที่มีผล วันนักขัตฤกษ์ต้นทางเมื่อเกี่ยวข้อง ตัวระบุบัญชีผู้บันทึกและผู้ยกเลิก เวลา และรหัสคำสั่งสำหรับกันการส่งซ้ำ
- **สิทธิ์และขั้นตอน** Manager บันทึกหรือยกเลิกสำหรับทุกทีมในตารางที่ประกาศใช้และยังไม่ล็อก มีผลทันทีหลังระบบบันทึกสำเร็จ พนักงานและหัวหน้ากะเห็นสถานะขาดงานของกะที่เป็นของตนเอง
- **ประวัติและการจัดเก็บ** เก็บผู้ทำและเวลาของทั้งสองการกระทำไว้ในหลักฐานที่จำกัดสิทธิ์ ส่วน API ตารางกะส่งสถานะปัจจุบันและข้อมูลกะเท่าที่จำเป็นตามบทบาท เก็บข้อมูลขาดงาน 12 เดือนจากการกระทำล่าสุด การยกเลิกเก็บหลักฐานเดิมไว้ ระเบียนหมดอายุถูกลบด้วยงานดูแลฐานข้อมูล และสรุปของเดือนที่อาจมีประวัติหมดอายุจะแจ้งว่ายืนยันยอดรวมไม่ได้
- **ความสอดคล้องของกะ** ใช้สถานะขาดงานคู่กับกะเดิม หากการอนุมัติหรือยกเลิกคำขอจะเปลี่ยนกะหรือสิทธิ์ OT ที่ผูกกับสถานะดังกล่าว ระบบให้ Manager ตรวจสอบและจัดการรายการขาดงานก่อน เพื่อให้การยกเลิกขาดงานคืนผลเดิมได้ถูกต้อง
